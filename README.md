# SNO-PI

SNOMED CT entity linking for clinical notes: high-recall span proposal, SapBERT candidate retrieval, and
ensemble reranking with pre-trained BERT-family encoders and curated terminology knowledge.

SNO-PI is a submission to SNOMED International's
[SNOMED CT Entity Linking Benchmark](https://www.drivendata.org/benchmarks/310/benchmark-snomed-ct/).

**The code will be released here once clean-up is finished.**

## Paper

Songsiritat P. *SNO-PI: Label-Scarce SNOMED CT Entity Linking with Pre-trained Encoders and Curated
Terminology Knowledge.* 2026. [[PDF]](paper/SNO-PI_Songsiritat_2026.pdf)

## Data

This repository will not contain any MIMIC-IV notes, annotations or models trained on them. Access to the
annotated notes requires PhysioNet credentialing:
[SNOMED CT Entity Linking Challenge](https://physionet.org/content/snomed-ct-entity-challenge/1.2.1/).
